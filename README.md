# StockWidget C# 重写版

这是 StockWidget 的 WPF/C# 重写版本，用于在 Windows 桌面悬浮显示股票和国内期货行情。

本版本没有逐行复刻 Python 原版，而是在保留核心盯盘能力的基础上，重新整理了配置、行情刷新、窗口交互、自选管理和持仓计算逻辑。`C#1` 分支只保存 C# 项目源码，不包含 Python 代码和构建产物。

## 主要改动

### 行情与显示

- 股票和国内期货使用独立的自选、勾选项、刷新间隔和显示指标配置。
- 股票盘口可同时显示买一和卖一，并支持数量、价格或两者同时显示。
- 显示指标按盘口指标、持仓指标和其他指标横向分类，K 线归入其他指标。
- 支持表头、网格、自适应列宽以及可选的手动拖动列宽；关闭网格或未启用自定义列宽时不会误触拖动。
- 所有数值按对应列左对齐，字体放大、负行距及较大正行距下会重新测量窗口尺寸，减少内容截断。
- 刷新间隔支持 `0.1` 秒至 `60` 秒，并提供悬浮窗右键手动刷新。
- 行情刷新增加并发保护，上一轮未完成时不会堆积新的请求。
- 区分无网络、接口空数据、解析失败和未选择显示项；异常时保留上一帧可用行情。

### 自选与持仓

- 自选列表支持添加、删除、编辑、上移、下移、勾选显示和滚动浏览。
- 股票 6 位代码可自动推断市场，国内期货代码使用 `nf_` 前缀。
- 双击或右键自选可编辑代码、持仓成本、持仓数量；期货还可选择做多或做空。
- 有持仓的自选使用红色标记；删除或修改代码时同步维护持仓记录。
- `All` 固定在自选列表顶部，不能删除或编辑，用于控制持仓汇总行。
- 持仓汇总会计算全部自选中的持仓，不受该品种是否勾选显示影响。
- 汇总行与普通行情行使用同一套列和对齐规则；无数据的持仓指标显示 `---`。
- 股票按成本价、数量和现价计算盈亏；期货按品种的每跳价差、每跳毛利及多空方向计算。
- 内置 87 个期货品种参数，可在“品种参数”中查看和修改。

### 设置与窗口行为

- 设置项即时应用；点击“取消”恢复打开设置前的配置，点击“确认”保存当前配置。
- 设置窗口和悬浮窗都会记住上次位置，并限制在当前屏幕工作区内。
- 支持可配置的边缘吸附及吸附距离，拖动时不会让窗口侧边移出桌面。
- 左键双击悬浮窗打开设置；右键可切换指标、刷新、自适应列宽和鼠标穿透。
- 鼠标穿透同时提供于悬浮窗右键菜单和任务栏托盘图标菜单。
- 支持可清空的全局显示/隐藏快捷键；清空后不再自动恢复旧快捷键。
- 支持开机启动、默认或自定义 `.ico` 图标。
- 保留浮窗与托盘模式，不包含已取消的任务栏 `SetParent` 嵌入功能。

### 外观

- 可设置字体、字号、行距、透明度、文字颜色、背景颜色和涨跌颜色。
- 屏幕取文字色位于文字颜色选择面板，屏幕取背景色位于背景颜色选择面板。
- 支持从桌面任意位置拾取颜色，并在确认或取消设置时正确保存或回滚。
- K 线使用 WPF 自绘控件，并随字体、行高、列宽和显示开关统一重绘。

## 项目结构

```text
StockWidgetCSharp/
|-- data/       新浪股票和期货行情解析
|-- models/     配置、行情、持仓及期货参数模型
|-- services/   行情刷新与全局热键服务
|-- views/      悬浮窗、设置、自选编辑、K 线等界面
|-- App.xaml    应用入口与托盘管理
`-- StockWidgetCSharp.csproj
```

## 构建

开发环境需要 Windows 10/11 x64 和 .NET 9 SDK。

```powershell
dotnet build .\StockWidgetCSharp\StockWidgetCSharp.csproj -c Release
```

发布 self-contained `win-x64` 版本：

```powershell
dotnet publish .\StockWidgetCSharp\StockWidgetCSharp.csproj -c Release -o .\dist\StockWidgetCSharp
```

发布版本自带 .NET 运行环境，目标电脑无需另行安装 .NET 9。`dist`、`bin` 和 `obj` 不提交到 `C#1` 源码分支。

## 配置

配置文件继续使用原项目路径：

```text
%APPDATA%\StockWidget\SW_config.json
```

程序兼容旧版主要 JSON 配置键，并分别保存股票/期货自选、显示项、持仓、期货品种参数、窗口位置和外观设置。

## 数据说明

- 行情数据来自新浪公开行情接口，程序运行时需要网络连接。
- 国内期货盈亏依赖对应品种的每跳价差和每跳毛利；缺少有效参数时以 `---` 显示，避免给出错误结果。
- 本工具仅用于行情展示和个人持仓估算，不构成投资建议。
